# Netflix-EDA
Exploratory Data Analysis (EDA) of the Netflix Movies &amp; TV Shows Dataset using Python, Pandas, Matplotlib, and Seaborn to uncover content trends, genre distribution, country-wise production patterns, and business insights.
# Netflix Movies & TV Shows - Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies & TV Shows dataset obtained from Kaggle. The goal is to understand content trends, identify patterns in Netflix's catalog, visualize important findings, and generate meaningful business insights through data analysis.

## Dataset

Source:
https://www.kaggle.com/datasets/shivamb/netflix-shows

The dataset contains information about Netflix titles including:

- Title
- Type (Movie/TV Show)
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genre
- Date Added

## Objectives

- Load and inspect the dataset
- Clean missing and duplicate values
- Perform exploratory data analysis
- Create visualizations to understand trends
- Generate data-driven insights and recommendations

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Data Cleaning

The following preprocessing steps were performed:

- Removed duplicate records
- Handled missing values
- Checked data types and corrected them where necessary
- Cleaned and formatted relevant columns

## Exploratory Data Analysis

The analysis answers key questions such as:

1. How many Movies and TV Shows are available on Netflix?
2. Which countries produce the most Netflix content?
3. What are the most common content ratings?
4. How has Netflix content grown over the years?
5. Which genres are most popular?

## Visualizations

The project includes multiple visualizations such as:

- Bar Charts
- Histograms
- Pie Charts
- Line Charts
- Scatter Plots
- Heatmaps

## Key Insights

- Movies significantly outnumber TV Shows on Netflix.
- Content production increased rapidly after 2015.
- A few countries contribute the majority of Netflix content.
- Certain content ratings dominate the platform.
- Specific genres consistently appear more frequently than others.

## Business Recommendations

1. Continue investing in high-performing genres.
2. Increase regional content production in emerging markets.
3. Expand successful TV Show categories.
4. Focus content acquisition strategies on audience-preferred ratings.
5. Use historical content trends for future content planning.
